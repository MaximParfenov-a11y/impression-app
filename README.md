# IMPRESSION

**Поисковик впечатлений — Санкт-Петербург и Ленинградская область.**

> Ты не ищешь место. Ты ищешь впечатление — приложение находит место.

## MVP уже содержит
- Главный экран «Куда хочется сегодня?»
- Естественный текстовый поиск
- Подбор по ощущениям
- Match % и ранжирование
- 40 стартовых структурированных объектов СПб/ЛО
- Детальные карточки мест
- Практические советы и safety notes
- Внешний маршрут через Яндекс Карты без картографического API в MVP
- Карта-каталог
- Сохранённое и профиль
- Архитектуру под Supabase + AI parser

## Запуск

```bash
npm install
npx expo start --web
```

## Важное правило данных
AI не имеет права придумывать места. Он только переводит человеческий запрос в фильтры/веса, после чего backend выбирает объект только из проверенного каталога.

Перед публичным запуском каждый объект должен пройти отдельную верификацию координат, доступа, режима работы, цены, безопасности, источников и прав на фотографии.
